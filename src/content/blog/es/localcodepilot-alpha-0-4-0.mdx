LocalCodePilot llegó a `0.4.0-alpha.6` con un cambio importante: además de encontrar e iniciar proyectos, la aplicación ahora explica mejor el estado del entorno y reúne más herramientas para investigar problemas locales.

La versión combina diagnóstico de bases de datos, health checks HTTP, operaciones confirmadas de containers, inicio más rápido, tarjetas consistentes y una nueva página de ayuda. El objetivo sigue siendo reducir el contexto que el desarrollador debe mantener en la cabeza al cambiar de proyecto.

## Las bases de datos forman parte del diagnóstico

Alpha 6 reconoce configuraciones de PostgreSQL, MySQL, MariaDB, SQL Server y SQLite en los archivos de entorno del proyecto. Para servidores locales, la aplicación comprueba si la dirección y el puerto responden y ofrece orientación cuando el servicio no está disponible.

Las credenciales no se muestran en la interfaz. El servidor permanece bajo gestión del usuario: LocalCodePilot informa su estado, pero no instala ni inicia automáticamente PostgreSQL, MySQL, SQL Server u otro proveedor.

## Salud HTTP más allá de un puerto abierto

Un puerto abierto no garantiza que la aplicación esté saludable. Los procesos locales ahora reciben health checks HTTP asíncronos con código de estado, tiempo de respuesta y timeout.

La página **Procesos** combina estas señales con el estado del puerto y los logs. Esto ayuda a distinguir una aplicación saludable de un proceso activo que responde con error o dejó de atender solicitudes.

## Containers con confirmación

La página **Containers** ya no se limita al diagnóstico. Con Docker o Podman instalado y en ejecución, LocalCodePilot puede validar archivos Compose, iniciar y detener entornos, consultar estado y logs y construir Dockerfiles aislados.

Antes de cada operación, la aplicación muestra el comando y la carpeta de trabajo. El usuario debe confirmarlo, y las operaciones largas pueden cancelarse o finalizar por timeout. El flujo fue validado con Docker Desktop y Podman en Windows 11.

## Una interfaz más predecible

El catálogo guardado aparece al iniciar mientras el descubrimiento y los diagnósticos se actualizan en segundo plano. Las tarjetas de la vista general ahora mantienen una altura y una posición de acciones consistentes, reduciendo cambios visuales entre proyectos.

La nueva página **Ayuda** reúne el primer uso, los estados mostrados, orientación para bases de datos y containers y una secuencia breve para investigar fallos. Está disponible directamente en la barra lateral.

## Windows como foco y macOS para pruebas

Windows 10 y 11 x64 siguen siendo el objetivo principal de esta alpha. La versión también incluye un DMG universal experimental para Mac Intel y Apple Silicon, todavía con firma ad hoc y sin notarización. Este paquete amplía las pruebas en equipos reales antes de anunciar soporte estable para macOS.

`0.4.0-alpha.6` está disponible en la [página de la versión](https://github.com/cjulio1993/LocalCodePilot/releases/tag/v0.4.0-alpha.6), con ZIP y ejecutable para Windows, DMG experimental para macOS y hashes SHA-256. El código sigue abierto en el [repositorio de LocalCodePilot](https://github.com/cjulio1993/LocalCodePilot).
